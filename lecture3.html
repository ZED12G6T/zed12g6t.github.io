🏛️ انحدار الدالة القياسية (Gradient of a Scalar Field)

1. الرمز والتعريف (Symbol & Definition)

  • مؤشر الانحدار: يُرمز له بالرمز \(\nabla\) (ويُسمى Del أو Nabla).
  • تعريف الانحدار: إذا كانت لدينا دالة قياسية \(f(x, y, z)\) معرفة وقابلة للمفاضلة، فإن انحدار الدالة \(f\) يُرمز له بالرمز \(\text{grad}(f)\) أو \(\nabla f\).

2. القوانين الأساسية (Mathematical Formula)

النتيجة الناتجة من الانحدار تكون متجهاً (Vector) دائماً، ويمكن التعبير عنه بصيغتين:

1. صيغة الأحداثيات:

\[ \nabla f = \left[ \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right] \]

2. صيغة متجهات الوحدة (\(\hat{i}, \hat{j}, \hat{k}\)):

\[ \text{grad}(f) = \frac{\partial f}{\partial x} \hat{i} + \frac{\partial f}{\partial y} \hat{j} + \frac{\partial f}{\partial z} \hat{k} \]

3. مثال محلول (Example 1)

  • المسألة: أوجد \(\nabla f\) عند النقطة \((1, 0, 1)\) إذا كانت \(f(x, y, z) = x^2 + y^2 + z^2\).
  • خطوات الحل:
  1. حساب المشتقات الجزئية:
  • بالنسبة لـ \(x\):
\[ \frac{\partial f}{\partial x} = 2x \]
  • بالنسبة لـ \(y\):
\[ \frac{\partial f}{\partial y} = 2y \]
  • بالنسبة لـ \(z\):
\[ \frac{\partial f}{\partial z} = 2z \]
  1. التعويض بالنقطة \((1, 0, 1)\):
\[ \frac{\partial f}{\partial x} = 2(1) = 2 \]
\[ \frac{\partial f}{\partial y} = 2(0) = 0 \]
\[ \frac{\partial f}{\partial z} = 2(1) = 2 \]
  1. الناتج النهائي:
\[ \nabla f = 2\hat{i} + 2\hat{k} \quad \text{أو} \quad \nabla f = [2, 0, 2] \]

المثال الثاني (Example 2)

  • الدالة المعطاة:
\[ f(x, y, z) = 3x^2 y^2 z + 2xy - z^2 + 1 \]
  • المطلوب: أوجد \(\nabla f\) عند النقطة \((1, 1, 1)\).
  • خطوات الحل:
  1. حساب المشتقات الجزئية:
\[ \frac{\partial f}{\partial x} = 6xy^2 z + 2y \]
\[ \frac{\partial f}{\partial y} = 6x^2 yz + 2x \]
\[ \frac{\partial f}{\partial z} = 3x^2 y^2 - 2z \]
  1. صيغة المتجه العامة:
\[ \nabla f = \left[ 6xy^2 z + 2y, \; 6x^2 yz + 2x, \; 3x^2 y^2 - 2z \right] \]
  1. التعويض بالنقطة \((1, 1, 1)\):
  • المركبة الأولى (\(x\)):
\[ 6(1)(1)^2 (1) + 2(1) = 6 + 2 = 8 \]
  • المركبة الثانية (\(y\)):
\[ 6(1)^2 (1)(1) + 2(1) = 6 + 2 = 8 \]
  • المركبة الثالثة (\(z\)):
\[ 3(1)^2 (1)^2 - 2(1) = 3 - 2 = 1 \]
  1. الناتج النهائي:
\[ \left. \nabla f \right|_{(1,1,1)} = [8, 8, 1] \]

المثال الثالث (Example 3)

  • الدالة المعطاة:
\[ f(x, y, z) = e^{xy} + \cos(xyz) + 3z \]
  • المطلوب: أوجد \(\nabla f\) عند النقطة \((0, \pi, 2)\).
  • خطوات الحل:
  1. حساب المشتقات الجزئية:
\[ \frac{\partial f}{\partial x} = y e^{xy} - yz \sin(xyz) \]
\[ \frac{\partial f}{\partial y} = x e^{xy} - xz \sin(xyz) \]
\[ \frac{\partial f}{\partial z} = -xy \sin(xyz) + 3 \]
  1. صيغة المتجه العامة:
\[ \nabla f = \left[ y e^{xy} - yz \sin(xyz), \; x e^{xy} - xz \sin(xyz), \; -xy \sin(xyz) + 3 \right] \]
  1. التعويض بالنقطة \((0, \pi, 2)\):

(ملاحظة: بما أن \(x = 0\) فإن \(xy = 0\) و \(xyz = 0\) و \(\sin(0) = 0\) و \(e^0 = 1\))

  • المركبة الأولى (\(x\)):
\[ \pi e^0 - (\pi)(2) \sin(0) = \pi(1) - 0 = \pi \]
  • المركبة الثانية (\(y\)):
\[ 0 \cdot e^0 - (0)(2) \sin(0) = 0 \]
  • المركبة الثالثة (\(z\)):
\[ -(0)(\pi) \sin(0) + 3 = 0 + 3 = 3 \]
  1. الناتج النهائي:
\[ \left. \nabla f \right|_{(0,\pi,2)} = [\pi, 0, 3] \]

المشتقة الاتجاهية (Directional Derivative)

1. التعريف والقانون (Definition & Formula)

  • إذا كانت \(f(x, y, z)\) دالة قياسية قابلة للمفاضلة، وكان الاتجاه معطى بالمجهد \(\mathbf{a}\) بحيث \(|\mathbf{a}| \neq 0\).
  • يُرمز للمشتقة الاتجاهية بالرمز \(D_{\mathbf{a}} f\) وتُعرف بالقانون التالي:
\[ D_{\mathbf{a}} f = \nabla f \cdot \frac{\mathbf{a}}{|\mathbf{a}|} \]
  • ملاحظة: \(\frac{\mathbf{a}}{|\mathbf{a}|}\) هو متجه الوحدة (Unit Vector) في اتجاه المتجه \(\mathbf{a}\).

2. مثال محلول (Example)

  • المسألة: أوجد المشتقة الاتجاهية للدالة \(f(x, y, z) = 2x^2 + 3y^2 + z^2\) عند النقطة \((2, 1, 3)\) في اتجاه المتجه \(\mathbf{a} = [1, 0, -2]\).
  • خطوات الحل:
  1. حساب الانحدار \(\nabla f\):
\[ \nabla f = [4x, 6y, 2z] \]
  1. التعويض بالنقطة \((2, 1, 3)\) في \(\nabla f\):
\[ \left. \nabla f \right|_{(2,1,3)} = [4(2), 6(1), 2(3)] = [8, 6, 6] \]
  1. حساب طول المتجه \(|\mathbf{a}|\):
\[ |\mathbf{a}| = \sqrt{1^2 + 0^2 + (-2)^2} = \sqrt{1 + 0 + 4} = \sqrt{5} \]
  1. تطبيق قانون المشتقة الاتجاهية (الضرب القياسي Dot Product):
\[ D_{\mathbf{a}} f = [8, 6, 6] \cdot \frac{[1, 0, -2]}{\sqrt{5}} \]
\[ D_{\mathbf{a}} f = \frac{(8)(1) + (6)(0) + (6)(-2)}{\sqrt{5}} = \frac{8 + 0 - 12}{\sqrt{5}} = -\frac{4}{\sqrt{5}} \]

الانحدار كمتجه عمودي على السطح (Gradient as Surface Normal Vector)

1. المفهوم والتعريف (Definition)

  • إذا كان لدينا سطح \(S\) ممثل بالمعادلة \(f(x, y, z) = c\) (حيث \(c\) ثابت)، وكانت الدالة \(f\) قابلة للمفاضلة.
  • فإن متجه الانحدار \(\nabla f\) عند أي نقطة \(P\) على السطح يكون متجهاً عمودياً (Normal Vector) على السطح عند تلك النقطة.
  • المتجه العمودي:
\[ \text{Surface Normal Vector} = \nabla f \]
  • متجه الوحدة العمودي (\(\mathbf{n}\)):
\[ \mathbf{n} = \frac{\nabla f}{|\nabla f|} \]

2. التوضيح الهندسي للعمودي والمستوى المماس (SVG)

الشكل الهندسي الموضّح يبيّن العلاقة بين السطح المنحني \(f = c\)، والمستوى المماس عند نقطة التماس، ومتجه الانحدار العمودي \(\nabla f\):

3. مثال محلول (Example)

  • المسألة: أوجد متجه الوحدة العمودي \(\mathbf{n}\) لسطح المخروط \(z^2 = 4(x^2 + y^2)\) عند النقطة \(P(1, 0, 2)\).
  • خطوات الحل:
  1. إعادة ترتيب معادلة السطح وجعلها تساوي صفراً (\(f = 0\)):
\[ f(x, y, z) = 4(x^2 + y^2) - z^2 = 4x^2 + 4y^2 - z^2 = 0 \]
  1. حساب متجه العمودي \(\nabla f\):
\[ \nabla f = \left[ \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right] = [8x, 8y, -2z] \]
  1. التعويض بالنقطة \(P(1, 0, 2)\):
\[ \left. \nabla f \right|_{(1,0,2)} = [8(1), 8(0), -2(2)] = [8, 0, -4] \]
  1. حساب مقدار (طول) المتجه \(|\nabla f|\):
\[ |\nabla f| = \sqrt{8^2 + 0^2 + (-4)^2} = \sqrt{64 + 0 + 16} = \sqrt{80} \]
  1. إيجاد متجه الوحدة العمودي (\(\mathbf{n}\)):
\[ \mathbf{n} = \frac{\nabla f}{|\nabla f|} = \frac{[8, 0, -4]}{\sqrt{80}} \]

حل الواجب (Class Work Solution)

المسألة:

أوجد متجه الوحدة العمودي \(\mathbf{n}\) للسطح:

\[ f(x, y, z) = \frac{x^2}{8} + \frac{y^2}{9} - \frac{z^2}{2} = 1 \]

عند النقطة \(P(4, 3, 2)\).

اضغط هنا لإظهار خطوات الحل والناتج

خطوات الحل:

  1. إيجاد المشتقات الجزئية لحساب المتجه العمودي \(\nabla f\):
\[ \frac{\partial f}{\partial x} = \frac{2x}{8} = \frac{x}{4} \]
\[ \frac{\partial f}{\partial y} = \frac{2y}{9} \]
\[ \frac{\partial f}{\partial z} = -\frac{2z}{2} = -z \]

فيكون صيغة الانحدار العام:

\[ \nabla f = \left[ \frac{x}{4}, \; \frac{2y}{9}, \; -z \right] \]
  1. التعويض بالنقطة \(P(4, 3, 2)\) في \(\nabla f\):
  • بالنسبة لـ \(x\): \(\frac{4}{4} = 1\)
  • بالنسبة لـ \(y\): \(\frac{2(3)}{9} = \frac{6}{9} = \frac{2}{3}\)
  • بالنسبة لـ \(z\): \(-(2) = -2\)

المتجه العمودي عند النقطة هو:

\[ \nabla f = \left[ 1, \; \frac{2}{3}, \; -2 \right] \]
  1. حساب مقدار (طول) المتجه \(|\nabla f|\):
\[ |\nabla f| = \sqrt{(1)^2 + \left(\frac{2}{3}\right)^2 + (-2)^2} \]
\[ |\nabla f| = \sqrt{1 + \frac{4}{9} + 4} = \sqrt{5 + \frac{4}{9}} = \sqrt{\frac{49}{9}} = \frac{7}{3} \]
  1. إيجاد متجه الوحدة العمودي \(\left(\mathbf{n} = \frac{\nabla f}{|\nabla f|}\right)\):
\[ \mathbf{n} = \frac{\left[ 1, \; \frac{2}{3}, \; -2 \right]}{\frac{7}{3}} \]

بضرب كل مركبة في القيمة العكسية \(\frac{3}{7}\):

  • المركبة الأولى: \(1 \times \frac{3}{7} = \frac{3}{7}\)
  • المركبة الثانية: \(\frac{2}{3} \times \frac{3}{7} = \frac{2}{7}\)
  • المركبة الثالثة: \(-2 \times \frac{3}{7} = -\frac{6}{7}\)

الناتج النهائي:

\[ \mathbf{n} = \left[ \frac{3}{7}, \; \frac{2}{7}, \; -\frac{6}{7} \right] = \frac{3}{7}\hat{i} + \frac{2}{7}\hat{j} - \frac{6}{7}\hat{k} \]
