انحدار الدالة القياسية والمشتقة الاتجاهية

متجه $\nabla f$ يشير دائماً عمودياً على منحنى المستوى $f = c$، في اتجاه أقصى تزايد للدالة

منحنى المستوى f(x,y,z) = c ∇f — عمودي على المنحنى
01 ∇

انحدار الدالة القياسية (Gradient of a Scalar Field)

الرمز والتعريف

  • مؤشر الانحدار: يُرمز له بالرمز $\nabla$ (ويُسمى Del أو Nabla).
  • تعريف الانحدار: إذا كانت لدينا دالة قياسية $f(x, y, z)$ معرفة وقابلة للمفاضلة، فإن انحدارها يُرمز له بـ $\text{grad}(f)$ أو $\nabla f$.

القوانين الأساسية

النتيجة الناتجة من الانحدار تكون متجهاً (Vector) دائماً، ويمكن التعبير عنه بصيغتين:

صيغة الإحداثيات \[ \nabla f = \left[ \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right] \]
صيغة متجهات الوحدة (î, ĵ, k̂) \[ \text{grad}(f) = \frac{\partial f}{\partial x} \hat{i} + \frac{\partial f}{\partial y} \hat{j} + \frac{\partial f}{\partial z} \hat{k} \]

مثال محلول 1

المسألة: أوجد $\nabla f$ عند النقطة $(1, 0, 1)$ إذا كانت $f(x, y, z) = x^2 + y^2 + z^2$.

  1. حساب المشتقات الجزئية:
\[ \frac{\partial f}{\partial x} = 2x, \quad \frac{\partial f}{\partial y} = 2y, \quad \frac{\partial f}{\partial z} = 2z \]
  1. التعويض بالنقطة $(1, 0, 1)$:
\[ 2(1)=2, \quad 2(0)=0, \quad 2(1)=2 \]
الناتج النهائي: \[ \nabla f = 2\hat{i} + 2\hat{k} \quad \text{أو} \quad \nabla f = [2, 0, 2] \]
02

أمثلة إضافية على الانحدار

مثال محلول 2

\[ f(x, y, z) = 3x^2 y^2 z + 2xy - z^2 + 1 \]

المطلوب: أوجد $\nabla f$ عند النقطة $(1, 1, 1)$.

  1. المشتقات الجزئية:
\[ \frac{\partial f}{\partial x} = 6xy^2 z + 2y, \quad \frac{\partial f}{\partial y} = 6x^2 yz + 2x, \quad \frac{\partial f}{\partial z} = 3x^2 y^2 - 2z \]
  1. صيغة المتجه العامة:
\[ \nabla f = \left[ 6xy^2 z + 2y, \; 6x^2 yz + 2x, \; 3x^2 y^2 - 2z \right] \]
  1. التعويض بالنقطة $(1, 1, 1)$: $6+2=8$ ، $6+2=8$ ، $3-2=1$
الناتج النهائي: \[ \left. \nabla f \right|_{(1,1,1)} = [8, 8, 1] \]

مثال محلول 3

\[ f(x, y, z) = e^{xy} + \cos(xyz) + 3z \]

المطلوب: أوجد $\nabla f$ عند النقطة $(0, \pi, 2)$.

  1. المشتقات الجزئية:
\[ \frac{\partial f}{\partial x} = y e^{xy} - yz \sin(xyz), \quad \frac{\partial f}{\partial y} = x e^{xy} - xz \sin(xyz), \quad \frac{\partial f}{\partial z} = -xy \sin(xyz) + 3 \]

بما أن $x = 0$ فإن $xy = 0$ و $xyz = 0$ و $\sin(0) = 0$ و $e^0 = 1$

  1. التعويض بالنقطة $(0, \pi, 2)$:
\[ \pi e^0 - 0 = \pi, \qquad 0 \cdot e^0 - 0 = 0, \qquad -0 + 3 = 3 \]
الناتج النهائي: \[ \left. \nabla f \right|_{(0,\pi,2)} = [\pi, 0, 3] \]
03 Dₐ

المشتقة الاتجاهية (Directional Derivative)

التعريف والقانون

  • إذا كانت $f(x, y, z)$ دالة قياسية قابلة للمفاضلة، وكان الاتجاه معطى بالمتجه $\mathbf{a}$ بحيث $|\mathbf{a}| \neq 0$.
  • يُرمز للمشتقة الاتجاهية بـ $D_{\mathbf{a}} f$ وتُعرف بالقانون:
\[ D_{\mathbf{a}} f = \nabla f \cdot \frac{\mathbf{a}}{|\mathbf{a}|} \]

حيث $\frac{\mathbf{a}}{|\mathbf{a}|}$ هو متجه الوحدة في اتجاه المتجه $\mathbf{a}$.

مثال محلول

المسألة: أوجد المشتقة الاتجاهية للدالة $f(x, y, z) = 2x^2 + 3y^2 + z^2$ عند النقطة $(2, 1, 3)$ في اتجاه المتجه $\mathbf{a} = [1, 0, -2]$.

  1. حساب الانحدار العام:
\[ \nabla f = [4x, 6y, 2z] \]
  1. التعويض بالنقطة $(2, 1, 3)$:
\[ \left. \nabla f \right|_{(2,1,3)} = [4(2), 6(1), 2(3)] = [8, 6, 6] \]
  1. حساب طول المتجه $|\mathbf{a}|$:
\[ |\mathbf{a}| = \sqrt{1^2 + 0^2 + (-2)^2} = \sqrt{5} \]
  1. تطبيق القانون (الضرب القياسي):
\[ D_{\mathbf{a}} f = [8, 6, 6] \cdot \frac{[1, 0, -2]}{\sqrt{5}} = \frac{8 + 0 - 12}{\sqrt{5}} \]
الناتج النهائي: \[ D_{\mathbf{a}} f = -\frac{4}{\sqrt{5}} \]
04 n̂

الانحدار كمتجه عمودي على السطح

  • إذا كان لدينا سطح $S$ ممثل بالمعادلة $f(x, y, z) = c$ (حيث $c$ ثابت)، وكانت $f$ قابلة للمفاضلة.
  • فإن متجه الانحدار $\nabla f$ عند أي نقطة $P$ على السطح يكون متجهاً عمودياً (Normal Vector) على السطح عند تلك النقطة.
\[ \text{Surface Normal Vector} = \nabla f \]

متجه الوحدة العمودي:

\[ \mathbf{n} = \frac{\nabla f}{|\nabla f|} \]

التوضيح الهندسي

العلاقة بين السطح المنحني $f = c$، والمستوى المماس عند نقطة التماس، ومتجه الانحدار العمودي $\nabla f$:

مثال محلول

المسألة: أوجد متجه الوحدة العمودي $\mathbf{n}$ لسطح المخروط $z^2 = 4(x^2 + y^2)$ عند النقطة $P(1, 0, 2)$.

  1. إعادة ترتيب معادلة السطح ($f = 0$):
\[ f(x, y, z) = 4x^2 + 4y^2 - z^2 = 0 \]
  1. حساب متجه العمودي $\nabla f$:
\[ \nabla f = [8x, 8y, -2z] \]
  1. التعويض بالنقطة $P(1, 0, 2)$:
\[ \left. \nabla f \right|_{(1,0,2)} = [8, 0, -4] \]
  1. حساب مقدار المتجه $|\nabla f|$:
\[ |\nabla f| = \sqrt{64 + 0 + 16} = \sqrt{80} \]
متجه الوحدة العمودي: \[ \mathbf{n} = \frac{[8, 0, -4]}{\sqrt{80}} \]
05

حل الواجب (Class Work Solution)

المسألة أوجد متجه الوحدة العمودي $\mathbf{n}$ للسطح
\[ \frac{x^2}{8} + \frac{y^2}{9} - \frac{z^2}{2} = 1 \]
عند النقطة $P(4, 3, 2)$.
اضغط لعرض خطوات الحل
  1. المشتقات الجزئية لحساب $\nabla f$:
\[ \frac{\partial f}{\partial x} = \frac{x}{4}, \quad \frac{\partial f}{\partial y} = \frac{2y}{9}, \quad \frac{\partial f}{\partial z} = -z \]

فتكون صيغة الانحدار العام:

\[ \nabla f = \left[ \frac{x}{4}, \; \frac{2y}{9}, \; -z \right] \]
  1. التعويض بالنقطة $P(4, 3, 2)$:
  • $x$: $\frac{4}{4} = 1$
  • $y$: $\frac{2(3)}{9} = \frac{2}{3}$
  • $z$: $-(2) = -2$
\[ \nabla f = \left[ 1, \; \frac{2}{3}, \; -2 \right] \]
  1. حساب مقدار المتجه $|\nabla f|$:
\[ |\nabla f| = \sqrt{1 + \frac{4}{9} + 4} = \sqrt{\frac{49}{9}} = \frac{7}{3} \]
  1. إيجاد متجه الوحدة العمودي $\mathbf{n} = \dfrac{\nabla f}{|\nabla f|}$:

بضرب كل مركبة في القيمة العكسية $\frac{3}{7}$: $1 \times \frac{3}{7} = \frac{3}{7}$، $\frac{2}{3} \times \frac{3}{7} = \frac{2}{7}$، $-2 \times \frac{3}{7} = -\frac{6}{7}$

الناتج النهائي: \[ \mathbf{n} = \left[ \frac{3}{7}, \; \frac{2}{7}, \; -\frac{6}{7} \right] = \frac{3}{7}\hat{i} + \frac{2}{7}\hat{j} - \frac{6}{7}\hat{k} \]
