الدفعات المؤجلة

Deferred annuity

↑
📐 القانون\(A(P/A)(P/F)\)

🔑 لما تشوف في السؤال When you see

  • first payment at the end of year k (not year 1)أول دفعة في نهاية السنة k (مو السنة 1)
  • starting N years from nowتبدأ بعد N سنة من الحين
  • grace periodفترة سماح
  • buy now, start paying in N monthsاشترِ الحين وابدأ تدفع بعد N شهر
  • earns nothing for the first yearsما يكسب شي أول السنين
  • first one at the beginning of year kأولها في بداية السنة k

🎯 والمطلوب What it asks for

\(P_J = A(P/A, i, N-J)\), then \(P_0 = P_J(P/F, i, J)\), where \(J\) is the period just before the first payment.

\(P_J = A(P/A, i, N-J)\)، بعدين \(P_0 = P_J(P/F, i, J)\)، و \(J\) هي الفترة اللي قبل أول دفعة.

⚠️ لا تخلط · Don't mix it up

Discount \(J\) periods, not \(J+1\). A first payment at the 'beginning of year 4' is point 3, so \(J = 2\).

رجّع \(J\) فترات بس، مو \(J+1\). أول دفعة في «بداية السنة 4» يعني النقطة 3، فـ \(J = 2\).

التدرج المنتظم: القيمة الحالية

Uniform gradient present worth (P/G)

↑
📐 القانون\(P = G(P/G)\)

🔑 لما تشوف في السؤال When you see

  • rises / increases by X every yearتزيد X كل سنة
  • X more each yearكل سنة أكثر بـ X
  • falls / drops by X each yearتنقص X كل سنة
  • 0, G, 2G… starts from nothing0، G، 2G… تبدأ من صفر
  • worth today / set aside todayكم تسوى اليوم / كم تجنب اليوم

🎯 والمطلوب What it asks for

P = A₁(P/A) ± G(P/G): a base annuity plus (or minus) a gradient from 0.

P = A₁(P/A) ± G(P/G): دفعة أساسية زائد (أو ناقص) تدرج يبدأ من صفر.

⚠️ لا تخلط · Don't mix it up

The first amount A₁ is not part of G: 1,000, 1,300, 1,600 → A₁ = 1,000 and G = 300.

أول مبلغ A₁ مو جزء من G: 1,000، 1,300، 1,600 ← A₁ = 1,000 و G = 300.

التدرج المنتظم: الدفعة والمستقبل

Gradient to annual & future (A/G, F/G)

↑
📐 القانون\(A = A_1 + G(A/G)\)

🔑 لما تشوف في السؤال When you see

  • rising by X a year → equal yearly amountتزيد X بالسنة ← مبلغ سنوي متساوي
  • compare with a flat yearly costقارن مع تكلفة سنوية ثابتة
  • level / uniform annual equivalentمكافئ سنوي ثابت
  • deposits grow by X: balance at the endإيداعات تزيد X: الرصيد بالنهاية
  • 10,000, 11,000, 12,000… set aside the same each year10,000، 11,000، 12,000… تجنب نفس المبلغ كل سنة

🎯 والمطلوب What it asks for

A = A₁ ± G(A/G); for the final balance F = A₁(F/A) + G(F/G).

A = A₁ ± G(A/G)، وللرصيد بالنهاية F = A₁(F/A) + G(F/G).

⚠️ لا تخلط · Don't mix it up

Same rising series: 'worth today' → P/G, 'per year' → A/G, 'at the end' → F/G.

نفس السلسلة اللي تزيد: «كم تسوى اليوم» ← P/G، «بالسنة» ← A/G، «بالنهاية» ← F/G.

التدرج الهندسي

Geometric gradient

↑
📐 القانون\(\tfrac{A_1[1 - (P/F)(F/P)]}{i - \bar f}\)

🔑 لما تشوف في السؤال When you see

  • grows x% a yearتكبر x% بالسنة
  • rises with inflationتزيد مع التضخم
  • falls x% every yearتنقص x% كل سنة
  • increases with salary raises (%)تزيد مع زيادة الراتب (%)
  • growth rate equals the interest rateنسبة النمو = نسبة الفائدة

🎯 والمطلوب What it asks for

P = A₁[1 − (P/F, i, N)(F/P, f̄, N)]/(i − f̄); if f̄ = i, P = A₁N/(1 + i).

P = A₁[1 − (P/F, i, N)(F/P, f̄, N)]/(i − f̄)، ولو f̄ = i فـ P = A₁N/(1 + i).

⚠️ لا تخلط · Don't mix it up

By the same AMOUNT → uniform gradient. By the same PERCENT → geometric. A decline is a negative f̄.

بنفس المقدار ← تدرج منتظم. بنفس النسبة ← تدرج هندسي. والنقص يعني f̄ سالبة.

الفائدة المتغيرة مع الوقت

Interest rate that varies over time

↑
📐 القانون\(P = F_N / \textstyle\prod(1 + i_k)\)

🔑 لما تشوف في السؤال When you see

  • x% in year 1, y% in year 2…x% في السنة 1، y% في السنة 2…
  • a teaser rate, then higherنسبة ترويجية وبعدين أعلى
  • rates are expected to changeالنسب متوقع تتغير
  • one constant rate with the same growthنسبة ثابتة وحدة تعطي نفس النمو

🎯 والمطلوب What it asks for

Multiply or divide by each year's (1 + ik) in turn: no single factor.

اضرب أو اقسم على (1 + ik) لكل سنة بالترتيب: ما فيه عامل واحد.

⚠️ لا تخلط · Don't mix it up

Don't average the rates and use one factor: discount year by year.

لا تاخذ متوسط النسب وتستخدم عامل واحد: رجّع سنة سنة.

الفائدة الاسمية والفعالة

Nominal & effective interest

↑
📐 القانون\(i = (1 + r/M)^M - 1\)

🔑 لما تشوف في السؤال When you see

  • compounded monthly / quarterly / semiannuallyمركبة شهرياً / ربع سنوياً / نص سنوياً
  • APR, nominal rateAPR، النسبة الاسمية
  • x% per monthx% بالشهر
  • what does it really cost per year?كم تكلف فعلياً بالسنة؟
  • compare banks with different compoundingقارن بنوك تركيبها مختلف

🎯 والمطلوب What it asks for

\(i = (1 + r/M)^M - 1\); or work per period with \(r/M\) and \(N \times M\).

\(i = (1 + r/M)^M - 1\)، أو اشتغل لكل فترة بـ \(r/M\) و \(N \times M\).

⚠️ لا تخلط · Don't mix it up

Payments match the compounding → just use r/M. Yearly payments with monthly compounding → find the effective i first.

لو الدفعات بنفس فترة التركيب ← استخدم r/M بس. دفعات سنوية وتركيب شهري ← طلّع i الفعالة أول.

التركيب المستمر

Continuous compounding

↑
📐 القانون\(i = e^r - 1\)

🔑 لما تشوف في السؤال When you see

  • compounded continuouslyمركبة بشكل مستمر
  • continuous compoundingتركيب مستمر
  • compare with yearly compoundingقارن مع التركيب السنوي

🎯 والمطلوب What it asks for

\(i = e^r - 1\); a single amount uses \(e^{rN}\) forward and \(e^{-rN}\) back.

\(i = e^r - 1\)؛ والمبلغ الواحد يستخدم \(e^{rN}\) لقدام و \(e^{-rN}\) لورا.

⚠️ لا تخلط · Don't mix it up

It is the limit of compounding more and more often, so it always beats the same r compounded monthly.

هذا حد التركيب الأكثر والأكثر، فدايم يغلب نفس r المركبة شهرياً.

دوال الإكسل المالية

Excel financial functions

↑
📐 القانون\(\texttt{PMT, NPER, RATE}\)

🔑 لما تشوف في السؤال When you see

  • spreadsheet / Excelإكسل / جدول بيانات
  • in one cell / which function?في خلية وحدة / أي دالة؟
  • without interest tablesبدون جداول فائدة
  • exact N or i (no interpolation)N أو i دقيقة (بدون استكمال)

🎯 والمطلوب What it asks for

PMT → payment, PV → today, FV → future, NPER → N, RATE → i.

PMT ← القسط، PV ← اليوم، FV ← المستقبل، NPER ← N، RATE ← i.

⚠️ لا تخلط · Don't mix it up

Money you pay is negative and money you get is positive; NPER and RATE need one of each.

الفلوس اللي تدفعها سالبة واللي تاخذها موجبة؛ و NPER و RATE يحتاجون وحدة من كل نوع.
