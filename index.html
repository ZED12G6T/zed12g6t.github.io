مثال تطبيقي شامل على المماسات

حساب متجه المماس، متجه المماس الموحد، ومعادلة خط المماس الوسيطية

1

المعطيات والمطلوب (Problem Statement)

المعطيات:

دالة المنحنى:

$$\mathbf{r}(t) = \langle 4 \cos t, 4 \sin t, 0 \rangle$$
المطلوب عند اللحظة \(t = 0\):
  • (a) متجه المماس \(\mathbf{r}'(0)\) (Tangent vector).
  • (b) متجه المماس الموحد \(\mathbf{u}(0)\) (Unit tangent vector).
  • (c) معادلة خط المماس الوسيطية \(\mathbf{q}(w)\) (Parametric tangent line).
2

خطوات الحل (Solution Steps)

المطلوب (a): إيجاد متجه المماس \(\mathbf{r}'(0)\)
خطوة 1

إيجاد المشتقة الأولى العامة \(\mathbf{r}'(t)\):

$$\mathbf{r}'(t) = \left\langle \frac{d}{dt}(4 \cos t), \frac{d}{dt}(4 \sin t), \frac{d}{dt}(0) \right\rangle = \langle -4 \sin t, 4 \cos t, 0 \rangle$$
خطوة 2

التعويض بـ \(t = 0\):

$$\mathbf{r}'(0) = \langle -4 \sin(0), 4 \cos(0), 0 \rangle = \langle 0, 4(1), 0 \rangle = \langle 0, 4, 0 \rangle$$
الناتج النهائي (a): \(\mathbf{r}'(0) = \langle 0, 4, 0 \rangle\)
المطلوب (b): إيجاد متجه المماس الموحد \(\mathbf{u}(0)\)
خطوة 1

حساب طول المتجه \(|\mathbf{r}'(0)|\):

$$|\mathbf{r}'(0)| = \sqrt{0^2 + 4^2 + 0^2} = \sqrt{16} = 4$$
خطوة 2

تطبيق قانون متجه المماس الموحد:

$$\mathbf{u}(0) = \frac{\mathbf{r}'(0)}{|\mathbf{r}'(0)|} = \frac{\langle 0, 4, 0 \rangle}{4} = \langle 0, 1, 0 \rangle$$
الناتج النهائي (b): \(\mathbf{u}(0) = \langle 0, 1, 0 \rangle\)
المطلوب (c): إيجاد معادلة خط المماس \(\mathbf{q}(w)\) عند \(t = 0\)
خطوة 1

حساب متجه الموضع عند \(t = 0\):

$$\mathbf{r}(0) = \langle 4 \cos(0), 4 \sin(0), 0 \rangle = \langle 4, 0, 0 \rangle$$
خطوة 2

التعويض في الصيغة العامة لـ \(\mathbf{q}(w)\):

$$\mathbf{q}(w) = \mathbf{r}(0) + w \mathbf{r}'(0)$$
$$\mathbf{q}(w) = \langle 4, 0, 0 \rangle + w \langle 0, 4, 0 \rangle$$
خطوة 3

تبسيط الناتج النهائي:

$$\mathbf{q}(w) = \langle 4 + 0, 0 + 4w, 0 + 0 \rangle = \langle 4, 4w, 0 \rangle$$
الناتج النهائي (c): \(\mathbf{q}(w) = \langle 4, 4w, 0 \rangle\)

مفهوم المماس ومعادلاته (Tangent to a Curve)

1

مفهوم المماس (Tangent to a Curve)

1. التعريف:

المماسات هي خطوط مستقيمة تمس المنحنى عند نقطة واحدة فقط (Straight lines touching a curve at one point).

2. متجه المماس (Tangent Vector):
  • يُرمز لمتجه المماس بالرمز \(\mathbf{r}'(t)\).
  • يُحسب باشتقاق كل مركبة من مركبات دالة الموضع \(\mathbf{r}(t)\).
$$\mathbf{r}'(t) = \langle x'(t), y'(t), z'(t) \rangle$$
2

متجه المماس الموحد (Unit Tangent Vector)

1. التعريف:

هو متجه مماس طوله/مقداره يساوي 1 (Unit vector) ويكون في نفس اتجاه حركة المنحنى.

2. الرمز والقانون:
  • يُرمز له بالرمز \(\mathbf{u}(t)\) (أو \(\mathbf{T}\) في بعض المراجع).
  • يُحسب بقسمة متجه المماس على طوله (مقداره):
$$\mathbf{u}(t) = \frac{\mathbf{r}'(t)}{|\mathbf{r}'(t)|}$$
3

معادلة خط المماس (Tangent Line Equation)

تُستخدم هذه المعادلة لتمثيل خط المماس المار بنقطة على المنحنى بصيغة وسيطية (Parametric Form):

1. دالة خط المماس \(\mathbf{q}(w)\):
$$\mathbf{q}(w) = \mathbf{r}(t) + w \mathbf{r}'(t)$$
  • \(\mathbf{r}(t)\): متجه الموضع عند النقطة المحمدة على المنحنى.
  • \(\mathbf{r}'(t)\): متجه المماس عند تلك النقطة.
  • \(w\): متغير وسيط جديد (Parameter) خاص بـ خط المماس لتفادي الخلط مع زمن المنحنى \(t\).

اتجاه الحركة وتمثيل القطع الناقص

1

اتجاه الحركة على المنحنى (Curve Orientation)

تتحدد حركة المتجه \(\mathbf{r}(t)\) على المنحنى باتجاهين رئيسيين بحسب تغير المتغير \(t\):

  1. الاتجاه الموجب (Positive Sense):
    • يكون اتجاه الحركة عكس عقارب الساعة (Counterclockwise).
  2. الاتجاه السالم (Negative Sense):
    • يكون اتجاه الحركة مع عقارب الساعة (Clockwise).
2

تمثيل القطع الناقص (Ellipse Representation)

القطع الناقص هو تعميم لشكل الدائرة لكن بأبعاد مختلفة على المحاور.

1. المعادلة الكارتيزية القياسية:
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$
  • \(a\): نصف المحور الأفقي (x-axis).
  • \(b\): نصف المحور الرأسي (y-axis).
2. الصيغة العامة للدالة المتجهة \(\mathbf{r}(t)\):
$$\mathbf{r}(t) = \langle a \cos t, b \sin t, 0 \rangle$$

المركبات الإحداثية تكون:

  • \(x(t) = a \cos t\)
  • \(y(t) = b \sin t\)
  • \(z(t) = 0\) (لأن الشكل محدد في المستوى \(xy\)).
شرح بياني تفاعلي للقطع الناقص والمتجه \(\mathbf{r}(t)\) مع اتجاه الحركة الموجب
3

مثال تطبيقي (Example)

المسألة:

أوجد الدالة المتجهة \(\mathbf{r}(t)\) للقطع الناقص المعطى بالمعادلة:

$$\frac{x^2}{9} + \frac{y^2}{4} = 1$$
خطوات الحل:
  1. إيجاد أنصاف المحاور (\(a\) و \(b\)):
    • \(a^2 = 9 \implies a = 3\)
    • \(b^2 = 4 \implies b = 2\)
  2. التعويض في الصيغة العامة:
    • نعوض بـ \(a = 3\) و \(b = 2\) داخل الدالة المتجهة:
    $$\mathbf{r}(t) = \langle 3 \cos t, 2 \sin t, 0 \rangle$$

تمثيل اللولب الدائري (Circular Helix)

1

تمثيل اللولب الدائري (Circular Helix)

اللولب الدائري هو منحنى ثلاثي الأبعاد يدور على شكل حلزوني (مثل السبرنق أو برغي المسامير) ويرتفع مع محور \(z\).

1. الصيغة العامة للدالة المتجهة \(\mathbf{r}(t)\):
$$\mathbf{r}(t) = \langle a \cos t, a \sin t, ct \rangle$$
  • \(a\): نصف قطر الدوران على المستويين \(x\) و \(y\).
  • \(c\): ثابت يحدد معدل الارتفاع أو الصعود على المحور \(z\).
2

الحالات الخاصة حسب قيمة المعامل \(c\) (حالات الارتفاع والدوران)

تتحدد طبيعة وشكل اللولب بناءً على إشارة وقيمة الثابت \(c\):

  1. عندما تكون \(c > 0\) (Right-handed screw):
    • يدور اللولب ويرتفع للأعلى بجهة اليد اليمنى (حركة برغي يمني).
  2. عندما تكون \(c < 0\) (Left-handed screw):
    • يدور اللولب ويهبط للأسفل أو يتجه بجهة اليد اليسرى.
  3. عندما تكون \(c = 0\) (\(x^2 + y^2 = a^2\) Circle):
    • ينعدم الارتفاع (\(z = 0\)) وترجع المعادلة إلى دائرة دائرية عادية في المستوى \(xy\).
3

مثال تطبيقي (Example)

المسألة:

أوجد الدالة المتجهة للولب دائري إذا كانت معطياته كالتالي (في أقصى اليمين):

الحل:
  • التعويض المباشر بـ \(a = 1\) و \(c = 1\) يعطي الدالة المتجهة:
$$\mathbf{r}(t) = \langle \cos t, \sin t, t \rangle$$

تطبيقات الدائرة في المستوى (xy-plane)

1

القاعدة العامة للدائرة في المستوى (xy-plane)

عند تمثيل دائرة مركزها نقطة الأصل \((0,0)\) ونصف قطرها \(a\) بدالة متجهة:

المعادلة الوسيطية للدائرة (Parametric Equation of a Circle):
$$\mathbf{r}(t) = \langle a \cos t, a \sin t, 0 \rangle$$
  • \(a\): نصف قطر الدائرة.
  • \(t\): المتغير الوسيط (الزاوية بالراديان).
  • المركبة الثالثة تكون \(0\) لأن الدائرة تقع بالكامل في المستوى \(xy\) (أي \(z = 0\)).
2

المثال التطبيقي (Example)

المعطيات:
$$x^2 + y^2 = 4, \quad z = 0$$
خطوات الحل:
  1. معادلة الدائرة هي \(x^2 + y^2 = a^2\)، وبما أن \(a^2 = 4\)، إذن نصف القطر \(a = 2\).
  2. بالتعويض في الصيغة العامة، تصبح الدالة المتجهة (Parametric Representation) هي:
    $$\mathbf{r}(t) = \langle 2 \cos t, 2 \sin t, 0 \rangle$$
3

تحديد النقاط على الدائرة بالتعويض في \(t\) (The Points)

نعوض بقيم زوايا شهيرة لـ \(t\) للوصول لإحداثيات النقاط على محیط الدائرة:

عند الزاوية \(t = 0\):
$$\mathbf{r}(0) = \langle 2 \cos(0), 2 \sin(0), 0 \rangle = \langle 2(1), 2(0), 0 \rangle = \langle 2, 0, 0 \rangle$$
(موقع النقطة على المحور الموجب لـ \(x\))
عند الزاوية \(t = \frac{\pi}{4}\) (زاوية \(45^\circ\)):
$$\mathbf{r}\left(\frac{\pi}{4}\right) = \left\langle 2 \cos\left(\frac{\pi}{4}\right), 2 \sin\left(\frac{\pi}{4}\right), 0 \right\rangle = \left\langle 2\left(\frac{\sqrt{2}}{2}\right), 2\left(\frac{\sqrt{2}}{2}\right), 0 \right\rangle = \langle \sqrt{2}, \sqrt{2}, 0 \rangle$$
(موقع النقطة في منتصف الربع الأول)
عند الزاوية \(t = \frac{\pi}{2}\) (زاوية \(90^\circ\)):
$$\mathbf{r}\left(\frac{\pi}{2}\right) = \left\langle 2 \cos\left(\frac{\pi}{2}\right), 2 \sin\left(\frac{\pi}{2}\right), 0 \right\rangle = \langle 2(0), 2(1), 0 \rangle = \langle 0, 2, 0 \rangle$$
(موقع النقطة على المحور الموجب لـ \(y\))

Curves, Arc length and Curvature

(المقاطع، طول القوس، والانحناء)
1

تعريف المنحنيات وأهميتها (Curves ★)

المفهوم:

المنحنيات في الفراغ (Curves in space) مهمة في حساب التفاضل والتكامل (Calculus) والفيزياء (Physics)، كتمثيل لمسار جسم متحرك (path of moving body).

التصنيف والتطبيقات:

تندرج تحت الهندسة التفاضلية (Differential Geometry) وحساب المتجهات (Vector Calculus / Surfaces in space) ولها ثلاثة تطبيقات عملية:

  • Engineering design (التصميم الهندسي)
  • Space travel (رحلات الفضاء)
  • Geography (الجغرافيا الخرائطية)
2

التعبير عن المنحنى بدالة متجهة

الرسم البياني:

منحنى في الفراغ \(C\) يتحدد عبر المحاور الإحداثية الثلاثية \((x, y, z)\).

متجه الموضع:

المتجه الممتد من نقطة الأصل إلى أي نقطة على المنحنى يُرمز له بـ \(\mathbf{r}(t)\) ويُسمى Position Vector.

المعادلة الوسيطية (Parametric Equation of C):

المنحنى \(C\) يُعبر عنه بدالة متجهة قابلة للتفاضل (Differentiable function – Vector function).

3

الصيغ الرياضية لـ \(\mathbf{r}(t)\)

تُكتب دالة متجه الموضع إما بـ:

صيغة متجهات الوحدة \(\mathbf{(i, j, k)}\):
$$\mathbf{r}(t) = x(t)\mathbf{i} + y(t)\mathbf{j} + z(t)\mathbf{k}$$
الصيغة الإحداثية \(\mathbf{(Component\ Form)}\):
$$\mathbf{r}(t) = \langle x(t), y(t), z(t) \rangle$$
