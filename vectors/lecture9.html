التكامل الخطي Line Integrals $\displaystyle\int_C f(x,y)\,ds$

بدل ما نجمع الدالة على خط مستقيم من $a$ إلى $b$، نجمعها وإحنا نمشي على منحنى $C$. السر كله: نكتب المنحنى بدلالة $t$، فيتحول التكامل إلى تكامل عادي في $t$ تعرف تحله.

x(t), y(t)f(x, y)ds ← الأزرق = المنحنى بدلالة t، الأخضر = الدالة (الارتفاع)، البرتقالي = طول القطعة الصغيرة على المنحنى
⚡ الزبدة في 30 ثانية
  1. اكتب المنحنى $C$ بدلالة باراميتر: $x = x(t),\ y = y(t),\ a \le t \le b$.
  2. بدّل كل شي بـ $t$: الدالة $f(x(t), y(t))$، و $ds = \sqrt{x'(t)^2 + y'(t)^2}\,dt$ (أو $dx = x'\,dt$ و $dy = y'\,dt$ إذا السؤال طلبهم).
  3. معنى $\int_C f\,ds$: مساحة "سياج" ارتفاعه $f$ واقف على المنحنى $C$. ومنها طلع قانون المساحة الجانبية للأسطوانة $2\pi r h$.

وش يعني تكامل على منحنى؟

نفس فكرة التكامل العادي، بس الطريق صار منحنى بدل خط مستقيم

في التكامل العادي $\int_a^b f(x)\,dx$ نقطّع المحور $x$ لقطع صغيرة $dx$ ونجمع $f \times dx$. في التكامل الخطي نقطّع المنحنى نفسه لقطع صغيرة طولها $\Z{ds}$، ونضرب كل قطعة بقيمة الدالة $\Y{f}$ عندها، ونجمع.

\[ \int_C \Y{f(x,y)}\,\Z{ds} \;=\; \int_a^b \Y{f\big(\X{x(t)},\X{y(t)}\big)}\;\Z{\sqrt{\big(x'(t)\big)^2+\big(y'(t)\big)^2}\,dt} \]

ليش الجذر؟ القطعة الصغيرة على المنحنى هي وتر مثلث صغير: ضلعه الأفقي $dx = x'\,dt$ وضلعه الرأسي $dy = y'\,dt$. فيثاغورس يعطيك $ds = \sqrt{dx^2+dy^2} = \sqrt{x'^2+y'^2}\,dt$. نفس قانون طول القوس اللي أخذناه في المحاضرة 2.

وش يمثل $\int_C f\,ds$؟

معنيين في المحاضرة

(1) إذا $f$ قوة
الشغل
$W = \int_a^b f\big(x(t),y(t)\big)\sqrt{x'^2+y'^2}\,dt$
إذا $f(x,y)$ تمثل قوة، التكامل يعطيك الشغل على طول المنحنى.
(2) إذا $f$ ارتفاع
مساحة سياج
$\text{Area} = \int_C f\,ds$
$f\,ds$ = مساحة شريحة رفيعة من السياج، والتكامل = مساحة السياج كله.
✅ حالة خاصة: إذا $f = 1$ صار $\int_C 1\,ds$ = طول المنحنى نفسه (طول القوس).

الطريقة خطوة بخطوة

نفس الخطوات في كل سؤال

  1. اكتب المنحنى بدلالة t$x = x(t),\ y = y(t)$ وحدود $t$. إذا معطى جاهز خذه، وإذا دائرة استخدم $x = r\cos t,\ y = r\sin t,\ 0 \le t \le 2\pi$.
  2. اشتقاحسب $x'(t)$ و $y'(t)$.
  3. جهّز العنصر$ds = \sqrt{x'^2+y'^2}\,dt$، أو $dx = x'\,dt$، أو $dy = y'\,dt$ حسب المطلوب.
  4. عوّض في الدالةبدّل $x$ و $y$ في $f$ بدلالة $t$.
  5. كامل في tتكامل عادي من $a$ إلى $b$.
مثال 1

نفس الدالة، ثلاث تكاملات: dx و dy و ds

خط مستقيمdx · dy · ds
\[ \int_C xy^2\,dx,\qquad \int_C xy^2\,dy,\qquad \int_C xy^2\,ds \qquad C:\ x = 3t,\ y = 4t,\ 0 \le t \le 1 \]

  1. اقرأ السؤال

    المنحنى معطى جاهز بدلالة $t$ (خط مستقيم من $(0,0)$ إلى $(3,4)$). نفس الدالة $xy^2$ بس ثلاث عناصر مختلفة.

    x = 3t, y = 4tt: 0 → 1

  2. بدّل الدالة بـ $t$

    \[ \Y{xy^2} = (\X{3t})(\X{4t})^2 = 3t \cdot 16t^2 = \Y{48t^3} \]

  3. جهّز العناصر الثلاثة

    $x' = 3$ و $y' = 4$:

    \[ dx = 3\,dt,\qquad dy = 4\,dt,\qquad \Z{ds} = \sqrt{3^2+4^2}\,dt = \Z{5\,dt} \]

  4. بالنسبة لـ $x$

    \[ \int_C xy^2\,dx = \int_0^1 48t^3 \cdot 3\,dt = 144\Big[\tfrac{t^4}{4}\Big]_0^1 = 36 \]

  5. بالنسبة لـ $y$

    \[ \int_C xy^2\,dy = \int_0^1 48t^3 \cdot 4\,dt = 192\Big[\tfrac{t^4}{4}\Big]_0^1 = 48 \]

  6. بالنسبة لطول القوس $s$

    \[ \int_C xy^2\,ds = \int_0^1 48t^3 \cdot \Z{5}\,dt = 240\Big[\tfrac{t^4}{4}\Big]_0^1 = 60 \]

    ⚠ الفخ هنا: $ds$ مو $dt$. لو نسيت الـ $5$ بيطلع لك $12$ وهو غلط.

  7. $36,\quad 48,\quad 60$

    الأجوبة بنسبة $3 : 4 : 5$ بالضبط مثل $dx : dy : ds$، لأن الجزء $\int_0^1 48t^3\,dt = 12$ مشترك وكل واحد مضروب بعامله ✓

مثال 2

المساحة الجانبية للأسطوانة = $2\pi r h$

مساحة سياجدائرة

استخدم التكامل الخطي عشان تثبت إن المساحة الجانبية $A$ لأسطوانة دائرية قائمة نصف قطرها $r$ وارتفاعها $h$ تساوي $2\pi r h$.

  1. اقرأ السؤال

    الجدار الجانبي للأسطوانة هو "سياج" واقف على الدائرة $C: x^2+y^2=r^2$، وارتفاعه في كل مكان $h$. يعني المساحة $= \int_C f\,ds$ مع $f(x,y) = h$.

    C: x² + y² = r²f = h

  2. اكتب الدائرة بدلالة $t$

    باتجاه عكس عقارب الساعة (الاتجاه الموجب):

    \[ \X{x = r\cos t},\qquad \X{y = r\sin t},\qquad 0 \le t \le 2\pi \]

  3. اشتق وجهّز $ds$

    \[ x' = -r\sin t,\qquad y' = r\cos t \]
    \[ \Z{ds} = \sqrt{(-r\sin t)^2 + (r\cos t)^2}\,dt = r\sqrt{\sin^2 t + \cos^2 t}\,dt = \Z{r\,dt} \]

    ⚠ $\sqrt{r^2} = r$ (مو $r^2$)، و $\sin^2 t + \cos^2 t = 1$.

  4. عوّض وكامل

    \[ A = \int_C \Y{h}\,ds = \int_0^{2\pi} \Y{h}\cdot \Z{r}\,dt = rh\int_0^{2\pi} 1\,dt = rh\,(2\pi) \]
  5. $A = 2\pi r h$

    افتح الجدار وافرده: يصير مستطيل طوله محيط الدائرة $2\pi r$ وعرضه $h$، ومساحته $2\pi r \times h$ ✓

دورك: تمارين

اكتب الكسر هكذا: 35/2 ، و π هكذا: pi

تمرين أسهل
\[ \int_C (x+y)\,ds,\qquad C:\ x = 3t,\ y = 4t,\ 0 \le t \le 1 \]

نفس منحنى مثال 1، يعني $ds = 5\,dt$. و $x + y = 7t$.

  1. بدّل بـ $t$

    \[ x + y = 3t + 4t = 7t,\qquad ds = 5\,dt \]

  2. كامل

    \[ \int_0^1 7t \cdot 5\,dt = 35\Big[\tfrac{t^2}{2}\Big]_0^1 = \tfrac{35}{2} \]
  3. $\tfrac{35}{2}$
تمرين بسهل
\[ \int_C y\,dx,\qquad C:\ x = t^2,\ y = t,\ 0 \le t \le 1 \]

هنا $dx$ مو $ds$، يعني بدون جذر: $dx = 2t\,dt$.

  1. جهّز $dx$

    \[ x' = 2t \;\Rightarrow\; dx = 2t\,dt \]

  2. عوّض وكامل

    \[ \int_0^1 t \cdot 2t\,dt = 2\Big[\tfrac{t^3}{3}\Big]_0^1 = \tfrac{2}{3} \]
  3. $\tfrac{2}{3}$
تمرين جمتوسط
\[ \int_C x\,ds,\qquad C:\ x = \cos t,\ y = \sin t,\ 0 \le t \le \tfrac{\pi}{2} \]

ربع دائرة نصف قطرها 1، يعني $ds = 1\cdot dt$.

  1. جهّز $ds$

    \[ ds = \sqrt{\sin^2 t + \cos^2 t}\,dt = dt \]

  2. كامل

    \[ \int_0^{\pi/2} \cos t\,dt = \big[\sin t\big]_0^{\pi/2} = 1 \]
  3. $1$
تمرين دتحدي

سياج واقف على ربع الدائرة $x^2+y^2=4$ في الربع الأول، وارتفاعه عند كل نقطة $f(x,y) = y$. كم مساحته؟

$x = 2\cos t,\ y = 2\sin t,\ 0 \le t \le \tfrac{\pi}{2}$، و $ds = 2\,dt$.

  1. اكتب المنحنى بدلالة $t$

    \[ x = 2\cos t,\quad y = 2\sin t,\quad 0 \le t \le \tfrac{\pi}{2},\qquad ds = 2\,dt \]

  2. كامل

    \[ \int_0^{\pi/2} 2\sin t \cdot 2\,dt = 4\big[-\cos t\big]_0^{\pi/2} = 4(0+1) = 4 \]
  3. $4$

الأخطاء اللي تضيّع الدرجات

كل خطأ جنبه التصحيح

نسيان الجذر في $ds$
$\int_C f\,ds = \int_a^b f\,dt$
كأن $ds = dt$.
$\int_a^b f\,\sqrt{x'^2+y'^2}\,dt$
لازم تضرب بطول السرعة.
حط جذر في $dx$ أو $dy$
$dx = \sqrt{x'^2+y'^2}\,dt$
الجذر خاص بـ $ds$ بس.
$dx = x'(t)\,dt$
و $dy = y'(t)\,dt$.
ترك $x$ و $y$ داخل التكامل
$\int_0^1 xy^2 \cdot 5\,dt$
خلط بين متغيرات.
$\int_0^1 48t^3 \cdot 5\,dt$
كل شي بدلالة $t$.
حدود غلط
$\int_0^3 \dots\,dt$
حطيت حدود $x$ (من 0 إلى 3).
$\int_0^1 \dots\,dt$
الحدود دايماً حدود $t$.
تبسيط الجذر في الدائرة
$\sqrt{r^2\sin^2 t + r^2\cos^2 t} = r^2$
نسيت تاخذ الجذر.
$= r\sqrt{\sin^2 t+\cos^2 t} = r$
طلّع $r^2$ من الجذر تصير $r$.

اختبر نفسك

اضغط على الجواب اللي تشوفه صح

إذا $x = 3t,\ y = 4t$ فإن $ds$ تساوي:

$\sqrt{3^2+4^2} = \sqrt{25} = 5$.

في $\int_C f\,dy$ نبدّل $dy$ بـ:

$dy$ بدون جذر، بس مشتقة $y$ ضرب $dt$.

إذا $f(x,y)$ ارتفاع سياج على $C$، فإن $\int_C f\,ds$ تعطي:

$f\,ds$ = مساحة شريحة رفيعة، والمجموع = مساحة السياج كله.

للدائرة $x = r\cos t,\ y = r\sin t$ قيمة $ds$:

$\sqrt{r^2\sin^2 t + r^2\cos^2 t} = r$.

$\int_C 1\,ds$ يساوي:

سياج ارتفاعه 1: مساحته = طوله = طول القوس.
