التكامل الثنائي فوق منطقة غير مستطيلة Type I · Type II

التكامل الثنائي يحسب الحجم تحت السطح $z = f(x,y)$ فوق منطقة $R$ حدودها منحنيات. نقسّم المنطقة شرائح: إما رأسية ($dy\,dx$) أو أفقية ($dx\,dy$).

Type I · dy dxType II · dx dyالشريحة ← الأزرق = الشريحة الرأسية، الأخضر = الأفقية، البرتقالي = الشريحة اللي نجمعها
⚡ الزبدة في 30 ثانية
  1. Type I (شريحة رأسية): $y$ بين دالتين في $x$، و $x$ بين رقمين: $\int_a^b\!\int_{g_1(x)}^{g_2(x)} f\,dy\,dx$.
  2. Type II (شريحة أفقية): $x$ بين دالتين في $y$، و $y$ بين رقمين: $\int_c^d\!\int_{h_1(y)}^{h_2(y)} f\,dx\,dy$.
  3. الحدود الخارجية أرقام ثابتة دايماً، والداخلية تعتمد على المتغير الخارجي بس.

الخلاصة الذهنية: Type I ضد Type II

مختبر الشريحة: شوف التكامل يتراكم

شغّل المسح وشوف كيف التكامل الخارجي يبني الناتج شريحة شريحة، وقارن تقريب ريمان ($n$ عمود) بالقيمة الدقيقة

المنطقة R ومنحنى A(s)أعمدة ريمانالشريحة الحالية
💡 كيف تقرا الرسم: الرسم الثاني هو "قيمة الشريحة" $A(s)$ = التكامل الداخلي، والمساحة تحته هي ناتج التكامل الخارجي. جرّب $n = 4$ وبعدين $n = 100$ ولاحظ كيف يقل الخطأ.

Type I: الشريحة الرأسية

Type I Region (Vertical Slice)

نستخدم التكامل الثنائي عشان نحسب الحجم $V$ تحت سطح الدالة $z = f(x,y)$ فوق منطقة $R$ غير مستطيلة. نقسّم المنطقة شرائح، إما رأسية أو أفقية.

  • عنصر المساحة: $dA = dy\,dx$
  • حدود $y$: تتغير بين دالتين في $x$: $g_1(x)$ (الحد السفلي) و $g_2(x)$ (الحد العلوي).
  • حدود $x$: بين رقمين ثابتين $a$ و $b$.
\[ V = \iint_R f(x,y)\,dA = \int_{\X{a}}^{\X{b}}\!\int_{g_1(x)}^{g_2(x)} f(x,y)\,dy\,\X{dx} \]

Type II: الشريحة الأفقية

Type II Region (Horizontal Slice)

  • عنصر المساحة: $dA = dx\,dy$
  • حدود $x$: تتغير بين دالتين في $y$: $h_1(y)$ (الحد الأيسر) و $h_2(y)$ (الحد الأيمن).
  • حدود $y$: بين رقمين ثابتين $c$ و $d$.
\[ V = \iint_R f(x,y)\,dA = \int_{\Y{c}}^{\Y{d}}\!\int_{h_1(y)}^{h_2(y)} f(x,y)\,dx\,\Y{dy} \]
مثال

الحجم تحت مستوى

Type Idy dxحجم

Find the volume $V$ under the plane $z = 8x + 6y$ over the region:

\[ R = \left\{ (x,y) : 0 \le x \le 1, \; 0 \le y \le 2x^2 \right\} \]

  1. اقرأ السؤال

    حدود $y$ تعتمد على $x$ ($0 \le y \le 2x^2$) وحدود $x$ أرقام ثابتة ($0 \le x \le 1$)، فنستخدم الشريحة الرأسية $dy\,dx$.

    y: 0 → 2x²x: 0 → 1

  2. اكتب التكامل

    \[ V = \int_{\X{0}}^{\X{1}} \int_{0}^{2x^2} (8x + 6y)\,dy\,\X{dx} \]

  3. كامل بالنسبة لـ $\Y{y}$ $x$ ثابت

    \[ \int (8x + 6y)\,dy = 8xy + 3y^2 \]

    عوّض الحدود من $y = 0$ إلى $y = 2x^2$:

    \[ \left[ 8xy + 3y^2 \right]_{0}^{2x^2} = 8x(2x^2) + 3(2x^2)^2 - 0 = 16x^3 + 12x^4 \]

    x

  4. كامل بالنسبة لـ $\X{x}$

    \[ V = \int_{0}^{1} (16x^3 + 12x^4)\,dx = \left[ 4x^4 + \tfrac{12}{5} x^5 \right]_{0}^{1} = 4 + \tfrac{12}{5} = \tfrac{32}{5} \]
  5. $V = \tfrac{32}{5} = 6.4$

    مساحة $R$ = $\int_0^1 2x^2\,dx = \frac23$، وأعلى قيمة للمستوى فوقها $8+12 = 20$، فالحجم لازم أقل من $20 \times \frac23 \approx 13.3$ ✓

Example 1

تكامل على مثلث: شريحة رأسية

Type Idy dx
\[ \int_{0}^{1} \int_{0}^{x} (xy + 4)\,dy\,dx \]

  1. اقرأ السؤال

    y: 0 → xx: 0 → 1

  2. كامل بالنسبة لـ $\Y{y}$ $x$ ثابت

    \[ \int (xy + 4)\,dy = \frac{xy^2}{2} + 4y \]

    عوّض الحدود من $0$ إلى $x$:

    \[ \left[ \frac{xy^2}{2} + 4y \right]_{0}^{x} = \frac{x^3}{2} + 4x \]

    x

  3. كامل بالنسبة لـ $\X{x}$

    \[ \int_{0}^{1} \left( \frac{x^3}{2} + 4x \right) dx = \left[ \frac{x^4}{8} + 2x^2 \right]_{0}^{1} = \frac{1}{8} + 2 = \frac{17}{8} \]
  4. $\tfrac{17}{8}$

    مساحة المثلث ½، والدالة $xy+4$ بين 4 و 5 عليه، فالجواب لازم بين 2 و 2.5. و $\frac{17}{8} = 2.125$ ✓

Type IIdx dy

    x: 0 → yy: 0 → 2

مثال المجسم

حجم مجسم محصور بمستويات (Tetrahedron)

Type Iحجم2x + y + 4z = 4

نحسب حجم مجسم ثلاثي الأبعاد محصور بين مستويات الإحداثيات الثلاثة والمستوى المائل $2x + y + 4z = 4$ باستخدام التكامل الثنائي.

Find the volume $V$ of the solid bounded by the three coordinate planes and the plane $2x + y + 4z = 4$.

  1. اقرأ السؤال

    الارتفاع هو $z$ من معادلة المستوى، والقاعدة $R$ هي المكان اللي يقطع فيه المستوى الأرض ($z = 0$).

  2. الدالة $f(x,y)$ = ارتفاع المجسم

    اعزل $z$ من معادلة المستوى:

    \[ 4z = 4 - 2x - y \implies \Z{z = \tfrac{1}{4}(4 - 2x - y)} \]

  3. حدود المنطقة $R$ (لما $z = 0$)

    \[ 2x + y = 4 \implies y = 4 - 2x \]
    • يقطع محور $x$ (لما $y = 0$) عند $x = 2$
    • يقطع محور $y$ (لما $x = 0$) عند $y = 4$
    y: 0 → 4 − 2xx: 0 → 2

  4. اكتب التكامل

    \[ V = \iint_R f(x,y)\,dA = \frac{1}{4} \int_{\X{0}}^{\X{2}} \int_{0}^{4-2x} (4 - 2x - y)\,dy\,\X{dx} \]

  5. كامل بالنسبة لـ $\Y{y}$ $x$ ثابت

    \[ \int (4 - 2x - y)\,dy = 4y - 2xy - \frac{y^2}{2} \]

    عوّض من $0$ إلى $(4 - 2x)$، وفك الأقواس:

    \[ 4(4 - 2x) = 16 - 8x, \qquad -2x(4 - 2x) = -8x + 4x^2 \]
    \[ \frac{(4 - 2x)^2}{2} = \frac{16 - 16x + 4x^2}{2} = 8 - 8x + 2x^2 \]

    جمّع الحدود:

    \[ (16 - 16x + 4x^2) - (8 - 8x + 2x^2) = 8 - 8x + 2x^2 \]

    x

  6. كامل بالنسبة لـ $\X{x}$

    \[ V = \frac{1}{4} \int_{0}^{2} (8 - 8x + 2x^2)\,dx = \frac{1}{4} \left[ 8x - 4x^2 + \frac{2x^3}{3} \right]_{0}^{2} \]
    \[ = \frac{1}{4} \left[ 16 - 16 + \frac{16}{3} \right] = \frac{1}{4} \times \frac{16}{3} = \frac{4}{3} \]
  7. $V = \tfrac{4}{3}$

    قانون حجم الهرم: $\frac13 \times$ مساحة القاعدة $\times$ الارتفاع $= \frac13 \times \left(\frac12 \cdot 2 \cdot 4\right) \times 1 = \frac43$ ✓ نفس الجواب بطريقتين!

الأخطاء الشائعة في التكاملات الثنائية

كل خطأ جنبه التصحيح

قلب الترتيب
$\int_0^1\!\int_0^{x} f\,dx\,dy$
حدود مكتوبة لـ $y$ بس معها $dx$.

الحدود الداخلية لازم تخص المتغير اللي تكامله أول.

بعد التكامل بالنسبة لـ $y$ تعوّض $g_1(x), g_2(x)$ مكان $x$.
$\left[8xy+3y^2\right]_{y=0}^{y=2x^2}$
عوّضها مكان $y$، لأنها حدود $y$.
فك القوس المربع غلط
$(4-2x)^2 = 16-4x^2$
$(4-2x)^2 = 16-16x+4x^2$
الحد الأوسط $2ab$ ما ينهمل.

تاخذ $4-2x-y$ كارتفاع مباشرة.
$z = \tfrac14(4-2x-y)$
في مسائل الحجم اعزل $z$ من معادلة المستوى أول (القسمة على 4 في مثال المجسم).
اختيار الاتجاه الأصعب
تختار شريحة أفقية لمنطقة حدها العلوي والسفلي دوال في $x$، وتضطر تعكس الدوال بدون داعي.
إذا الحد العلوي والسفلي دوال في $x$ فالرأسية أسهل. وبعض المناطق تنفع بالطريقتين: مثلث Example 2 هو نفسه $x \le y \le 2,\ 0 \le x \le 2$، فاختر اللي تكامله أسهل.

اختبر نفسك

5 أسئلة، اختر وتشوف التصحيح والسبب فوراً

وش عنصر المساحة $dA$ الصحيح لمنطقة Type I (شريحة رأسية)؟

في Type I نكامل بالنسبة لـ $y$ أول (بين دالتين في $x$) وبعدين $x$ بين رقمين ثابتين، فـ $dA = dy\,dx$.

متى نستخدم الترتيب $dx\,dy$ (Type II)؟

Type II نستخدمه لما يكون الحد الأيسر والأيمن للمنطقة دالتين في $y$.

كم ناتج $\int_{0}^{1} \int_{0}^{x} (xy + 4)\,dy\,dx$؟

الداخلي يعطي $\frac{x^3}{2} + 4x$، وبعدين $\int_0^1 = \frac18 + 2 = \frac{17}{8}$.

كم حجم المجسم المحصور بين مستويات الإحداثيات والمستوى $2x + y + 4z = 4$؟

$V = \frac14\int_0^2\!\int_0^{4-2x} (4 - 2x - y)\,dy\,dx = \frac43$.

في التكامل $\int_{a}^{b} \int_{g_1(x)}^{g_2(x)} f\,dy\,dx$، وش لازم تكون $a$ و $b$؟

الحدود الخارجية لازم تكون ثوابت. أي متغير فيها يعني إن ترتيب التكامل غلط.
