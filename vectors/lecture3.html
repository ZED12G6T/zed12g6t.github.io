الانحدار والمشتقة الاتجاهيةGradient and Directional Derivative $\nabla f$

الانحدار $\nabla f$ يحوّل دالة قياسية (رقم عند كل نقطة) إلى متجه يأشر على اتجاه أسرع زيادة للدالة، وهو دايماً عمودي على سطح المستوى $f = c$. ومنه نحسب المشتقة في أي اتجاه نبيه، والمتجه العمودي على أي سطح. The gradient $\nabla f$ turns a scalar function (a number at each point) into a vector that points where the function increases fastest, and it is always perpendicular to the level surface $f = c$. From it we get the derivative in any direction we like, and the normal vector to any surface.

f∇fa ← الأزرق = الدالة القياسية، الأخضر = متجه الانحدار، البرتقالي = الاتجاه المطلوب← blue = the scalar function, green = the gradient vector, orange = the chosen direction
⚡ الزبدة في 30 ثانية⚡ The whole lecture in 30 seconds
  1. $\nabla f = \left[f_x, f_y, f_z\right]$: اشتق جزئياً بالنسبة لكل متغير، والنتيجة متجه دايماً.$\nabla f = \left[f_x, f_y, f_z\right]$: take the partial derivative with respect to each variable; the result is always a vector.
  2. المشتقة الاتجاهية: $D_{\mathbf{a}}f = \nabla f \cdot \frac{\mathbf{a}}{|\mathbf{a}|}$. لا تنسى توحّد $\mathbf{a}$.Directional derivative: $D_{\mathbf{a}}f = \nabla f \cdot \frac{\mathbf{a}}{|\mathbf{a}|}$. Don't forget to normalize $\mathbf{a}$.
  3. للسطح $f(x,y,z) = c$: $\nabla f$ عمودي عليه، والعمودي الموحد $\mathbf{n} = \frac{\nabla f}{|\nabla f|}$.For a surface $f(x,y,z) = c$: $\nabla f$ is perpendicular to it, and the unit normal is $\mathbf{n} = \frac{\nabla f}{|\nabla f|}$.

انحدار الدالة القياسيةGradient of a scalar field

من رقم عند كل نقطة إلى سهم عند كل نقطةFrom a number at each point to an arrow at each point

الرمز $\nabla$ اسمه Del أو Nabla. إذا عندنا دالة قياسية $f(x,y,z)$ قابلة للاشتقاق، فانحدارها يُكتب $\text{grad}(f)$ أو $\nabla f$، وناتجه دايماً متجه. نكتبه بصيغتين:The symbol $\nabla$ is called Del or Nabla. If $f(x,y,z)$ is a differentiable scalar function, its gradient is written $\text{grad}(f)$ or $\nabla f$, and the result is always a vector. Two ways to write it:

صيغة الإحداثياتComponent form
$\Y{\nabla f} = \left[ \dfrac{\partial f}{\partial x},\ \dfrac{\partial f}{\partial y},\ \dfrac{\partial f}{\partial z} \right]$
متجهات الوحدةUnit vectors
$\text{grad}(f) = \dfrac{\partial f}{\partial x}\hat{i} + \dfrac{\partial f}{\partial y}\hat{j} + \dfrac{\partial f}{\partial z}\hat{k}$
🔑 الترتيب:The order: اشتق جزئياً (الباقي ثوابت) ← اكتب المتجه العام ← عوّض النقطة آخر شي.Take partial derivatives (others held constant) → write the general vector → plug in the point last.

المشتقة الاتجاهيةThe directional derivative

قد إيش تتغير الدالة لو مشيت باتجاه $\mathbf{a}$؟How fast does the function change if you walk in direction $\mathbf{a}$?

إذا $f(x,y,z)$ قابلة للاشتقاق، والاتجاه معطى بمتجه $\mathbf{a}$ بحيث $|\mathbf{a}| \neq 0$، فالمشتقة الاتجاهية:If $f(x,y,z)$ is differentiable and the direction is given by a vector $\mathbf{a}$ with $|\mathbf{a}| \neq 0$, the directional derivative is:

\[D_{\Z{\mathbf{a}}} f = \Y{\nabla f} \cdot \frac{\Z{\mathbf{a}}}{|\Z{\mathbf{a}}|}\]

$\frac{\mathbf{a}}{|\mathbf{a}|}$ هو متجه الوحدة باتجاه $\mathbf{a}$. نوحّده عشان يقيس الاتجاه بس، مو الطول.$\frac{\mathbf{a}}{|\mathbf{a}|}$ is the unit vector along $\mathbf{a}$. We normalize so that only the direction counts, not the length.

  1. $\nabla f$ العامThe general $\nabla f$المشتقات الجزئية الثلاثThe three partial derivatives
  2. عوّض النقطةPlug in the pointيطلع متجه أرقامYou get a vector of numbers
  3. احسب $|\mathbf{a}|$Compute $|\mathbf{a}|$$\sqrt{a_1^2+a_2^2+a_3^2}$
  4. الضرب القياسيDot productاضرب مركبة بمركبة واجمع، ثم اقسم على $|\mathbf{a}|$. النتيجة رقمMultiply component by component, add, divide by $|\mathbf{a}|$. The result is a number
✅ معلومة تفيدك في الفحصHandy check
  • أكبر قيمة ممكنة لـ $D_{\mathbf{a}}f$ هي $|\nabla f|$، وتصير لما $\mathbf{a}$ بنفس اتجاه $\nabla f$.The largest possible $D_{\mathbf{a}}f$ is $|\nabla f|$, reached when $\mathbf{a}$ points along $\nabla f$.
  • لو $\mathbf{a}$ عمودي على $\nabla f$ فالمشتقة الاتجاهية صفر (تمشي على سطح المستوى).If $\mathbf{a}$ is perpendicular to $\nabla f$, the directional derivative is zero (you're walking along the level surface).

الانحدار كمتجه عمودي على السطحThe gradient as a surface normal

أي سطح نكتبه $f(x,y,z) = c$، و $\nabla f$ عمودي عليهWrite any surface as $f(x,y,z) = c$, and $\nabla f$ is perpendicular to it

إذا السطح $S$ معادلته $f(x,y,z) = c$ ($c$ ثابت) و $f$ قابلة للاشتقاق، فـ $\nabla f$ عند أي نقطة $P$ على السطح هو متجه عمودي (Normal Vector) على السطح عند هذي النقطة.If the surface $S$ is $f(x,y,z) = c$ ($c$ constant) and $f$ is differentiable, then $\nabla f$ at any point $P$ on the surface is a normal vector to the surface at that point.

متجه عموديNormal vector
$\text{Normal} = \Y{\nabla f}$
العمودي الموحدUnit normal
$\mathbf{n} = \dfrac{\nabla f}{|\nabla f|}$
⚠️ انتبه:Careful: لو السطح معطى مثل $z^2 = 4(x^2+y^2)$، انقل كل شي لطرف واحد أول: $f = 4x^2 + 4y^2 - z^2 = 0$، وبعدين اشتق.If the surface is given like $z^2 = 4(x^2+y^2)$, move everything to one side first: $f = 4x^2 + 4y^2 - z^2 = 0$, then differentiate.

انحدار بسيط عند نقطةA simple gradient at a point

∇f(1, 0, 1)
\[f(x,y,z) = x^2 + y^2 + z^2 \quad \text{at } (1, 0, 1)\]

  1. المشتقات الجزئيةThe partial derivatives

    \[\frac{\partial f}{\partial x} = 2x, \qquad \frac{\partial f}{\partial y} = 2y, \qquad \frac{\partial f}{\partial z} = 2z\]

  2. عوّض $(1, 0, 1)$Plug in $(1, 0, 1)$

    $f$ = مربع البعد عن الأصل، فأسرع زيادة تكون للخارج، يعني بنفس اتجاه النقطة $(1,0,1)$ ✓$f$ is the squared distance from the origin, so it grows fastest straight outward, i.e. along $(1,0,1)$ itself ✓

مثال 2Example 2

انحدار دالة فيها حواصل ضربGradient of a function with products

∇f(1, 1, 1)
\[f(x,y,z) = 3x^2y^2z + 2xy - z^2 + 1 \quad \text{at } (1, 1, 1)\]

  1. المشتقات الجزئيةThe partial derivatives الباقي ثوابتothers constant

    الثابت $+1$ يختفي في كل المشتقات.The constant $+1$ vanishes in every derivative.

  2. المتجه العام ثم عوّضThe general vector, then plug in

    \[\nabla f = [6xy^2z + 2y,\ 6x^2yz + 2x,\ 3x^2y^2 - 2z] \;\Rightarrow\; [6+2,\ 6+2,\ 3-2]\]
  3. $\nabla f\big|_{(1,1,1)} = [8, 8, 1]$

    الدالة متماثلة في $x$ و $y$، والنقطة فيها $x = y$، فطبيعي أول مركبتين متساويتين ✓The function is symmetric in $x$ and $y$, and the point has $x = y$, so the first two components should match ✓

انحدار فيه أُسّية و cosA gradient with exponential and cosine

المشتقة الاتجاهيةA directional derivative

Dafa = [1, 0, −2]
\[f = 2x^2 + 3y^2 + z^2 \quad \text{at } (2, 1, 3), \qquad \Z{\mathbf{a}} = [1, 0, -2]\]
